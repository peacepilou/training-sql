# training-sql : la base de la boutique de Camille

Tu es sur la branche `start`, celle du départ du module SQL : elle ne contient encore aucun script.

Au chapitre « Du MPD au script SQL », tu écris toi-même les tables de Camille. La solution, et la boutique complète avec ses données, t'attendent sur la branche `main`. Tu y passeras au chapitre « Interroger : SELECT, WHERE, JOIN » :

```bash
git switch main
```
